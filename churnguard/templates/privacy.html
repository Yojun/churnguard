隱私與使用說明

我們處理什麼資料

你上傳、貼上、以連結提供，或在網頁表格手動輸入的訂單明細或會員摘要資料（可能包含顧客編號、姓名、聯絡管道等），僅用於產生你當次要看的分析結果。

「快速估算」頁面完全在你的瀏覽器內計算，你輸入的數字不會傳送到伺服器。

如何處理與保存

  • 資料只暫存在伺服器記憶體，閒置 {{ TTL_MIN }} 分鐘後自動刪除；你也可以在結果頁按「立即刪除資料」。
  • 程式不會把你的資料寫入資料庫，也不會用於分析以外的目的。上傳較大檔案時，伺服器在處理過程中可能暫時使用系統暫存區，處理完即移除。
  • 每位訪客只能存取自己的分析結果，其他人無法用連結讀取。
  • 主機平台的連線記錄可能包含 IP 與網址，但不含你的資料內容。

連結匯入

只會從你提供的網址下載一次資料{% if PUBLIC %}，且僅限 Google 試算表與 GitHub 的連結{% endif %}。

Claude 問答（若有開啟）

只會傳送彙總統計（人數、比例、月趨勢、品類風險等），不含姓名、顧客編號或任何個別顧客的資料。

不會發送訊息

本網站只產生推播名單與訊息文字，不會對你的顧客發送任何訊息。

你的責任

  • 請確認你有權處理這份資料，並已依個人資料保護法等規定取得顧客同意（或已去識別化）。
  • 實際進行行銷推播前，請確認顧客已同意接收，並提供退訂方式。
  • 預測結果是統計估計，僅供排序與決策參考，不保證準確。
